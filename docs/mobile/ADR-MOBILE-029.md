## Context

Field-tech mobile màn **Chi tiết phiếu PM** (`PMWorkOrderDetailView`) cần **đính ảnh bằng chứng cho TỪNG mục checklist** (vd đo áp lực, kiểm tra dây nguồn, dán tem) TRƯỚC khi `submitPmResult` — làm **bằng chứng NĐ98** cho thiết bị **Class C/D** (BR-08-06/BR-08-14: ảnh trước/sau PM bắt buộc với thiết bị nguy cơ cao). Endpoint `imm08.attach_pm_checklist_photo` **ĐÃ LIVE** @`api/imm08.py:62` (single-step multipart: server đọc `frappe.request.files["file"]`, tự validate + tạo `File` private + set `pm_checklist_result[idx].photo`, robust KHÔNG orphan như 2-bước `upload→file_url`) nhưng **CHƯA có trong OAS mirror** → codegen client mobile không sinh được method `attachPmChecklistPhoto` → app phải hardcode URL + tự build multipart body.

Vòng này **curate 1 path POST** `attach_pm_checklist_photo` vào `assetcore-mobile.openapi.yaml` với requestBody **`multipart/form-data` DUY NHẤT** → codegen sinh method upload type-safe. **CONTRACT-ONLY**: handler+service+hằng đã LIVE @source (thêm ở vòng trước cùng branch, uncommitted), KHÔNG đụng `.py` vòng này ⇒ KHÔNG reload gunicorn, KHÔNG migrate.
