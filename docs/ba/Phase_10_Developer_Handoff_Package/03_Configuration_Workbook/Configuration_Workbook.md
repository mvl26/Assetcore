## 9. Setup script

```bash
# 1. New site
bench new-site assetcore.<env>.local
bench --site assetcore.<env>.local install-app erpnext
bench --site assetcore.<env>.local install-app assetcore

# 2. Load fixtures
bench --site assetcore.<env>.local execute assetcore.setup.bootstrap.run

# 3. Verify
bench --site assetcore.<env>.local execute assetcore.setup.verify.check_baseline

# 4. Create initial admin + champion users
bench --site assetcore.<env>.local execute assetcore.setup.users.create_baseline
```
